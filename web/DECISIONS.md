# Decisiones técnicas

- `next`, `react` y `react-dom`: App Router y renderizado de la aplicación nueva.
- `@supabase/ssr` y `@supabase/supabase-js`: clientes con cookies y autenticación SSR.
- `tailwindcss` y `@tailwindcss/postcss`: utilidades CSS y compilación de Tailwind v4.
- `vitest`: pruebas unitarias sin requerir una base de datos real.
- `eslint` y `eslint-config-next`: chequeos de calidad para Next.js y TypeScript.
