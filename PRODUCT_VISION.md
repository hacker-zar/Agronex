# Agronex - Vision de Producto

## Que es Agronex

Agronex es una plataforma modular para resolver operaciones criticas del agro.

Su objetivo es construir modulos de alto valor para productores, contratistas, transportistas, tecnicos y otros actores del sector. Cada modulo debe resolver un problema concreto del campo con profundidad suficiente para ser util por si mismo.

Agronex no debe crecer como una coleccion de funciones sueltas. Debe crecer como un ecosistema de modulos completos, simples y valiosos.

## Arquitectura de producto

Agronex es la marca madre.

Los modulos pueden evolucionar como productos internos dentro del ecosistema:

- `NexuDrive`: contratacion y coordinacion de camiones, maquinaria y servicios operativos.
- Calculadora: costos, margenes, fletes, insumos, rentabilidad y escenarios.
- Diario digital: registro de labores, eventos, aplicaciones, clima y observaciones.
- Campanias: planificacion y seguimiento de campanias agricolas.
- `NexuTech` / `NexuService`: busqueda de tecnicos, mecanicos, asesores y servicios especializados.
- `NexuPlace`: comparacion de campos o terrenos para compra, alquiler o evaluacion.

La vision futura es amplia, pero la ejecucion debe ser secuencial y enfocada.

## Regla de crecimiento

Agronex crece por modulos completos, no por funciones a medio hacer.

No se debe construir todo a la vez. Cada modulo nuevo debe demostrar valor real antes de expandirse al siguiente.

Para decidir si un modulo merece prioridad, evaluar:

- Tiene un problema validado?
- Puede entregar valor sin depender de otros modulos futuros?
- Reduce tiempo, incertidumbre, costo o riesgo?
- Puede mostrarse y venderse con un flujo simple?
- Se puede construir bien con los recursos actuales?

Si la respuesta no es clara, el modulo queda en vision futura, no en MVP.

## Modulo actual: NexuDrive

NexuDrive es el primer modulo operativo de Agronex.

Es un marketplace B2B que conecta productores agropecuarios con contratistas y transportistas para resolver necesidades operativas del campo de forma rapida y confiable.

No es una red social, una aplicacion de mensajeria ni un ERP. El modulo gira alrededor de las contrataciones, no alrededor de perfiles.

## Problema principal

La investigacion inicial muestra que el mayor dolor actual para el primer MVP esta en la contratacion de camiones. Los productores suelen:

- Perder horas llamando.
- Depender solo de contactos conocidos.
- No saber quien esta disponible.
- Terminar pagando mas por falta de informacion.

## Objetivo del MVP

Validar que NexuDrive, como primer modulo de Agronex, puede reducir el tiempo necesario para encontrar, coordinar y contratar un camion.

El exito del MVP no se mide por cantidad de funciones. Se mide por:

- Menos llamadas.
- Menos uso de WhatsApp.
- Menor tiempo hasta conseguir un camion.
- Mayor confianza entre productor, contratista y transportista.

## Filosofia de producto

Cada nueva funcion dentro del modulo actual debe responder una pregunta:

> Reduce tiempo, incertidumbre o coordinacion?

Si la respuesta es no, probablemente no pertenece al MVP.

## Principios de UX

- Mobile first.
- Maximo una accion principal por pantalla.
- Reducir escritura.
- Priorizar botones y estados.
- Evitar chat cuando un cambio de estado resuelve el problema.
- Mantener el flujo extremadamente simple.

## Usuarios

Un mismo usuario puede ser productor y contratista.

NexuDrive no debe depender de perfiles complejos como centro del producto. El centro deben ser las solicitudes, aceptaciones, estados del trabajo y reputacion.

## Flujo principal

1. Disponibilidad.
2. Solicitud.
3. Aceptacion.
4. Negociacion de horario, si es necesaria.
5. Seguimiento del trabajo.
6. Ubicacion opcional durante el viaje.
7. Finalizacion.
8. Estado de pago.
9. Reputacion.

## Que no hacer

- No agregar funciones por intuicion.
- No copiar otras aplicaciones sin validar que resuelvan un problema real del agro.
- No aumentar pasos innecesarios.
- No reemplazar el flujo por un chat.
- No abrir varios modulos a la vez si eso deja a todos incompletos.

## Criterios para evaluar una propuesta

Antes de implementar cualquier cambio, responder:

- Resuelve un problema validado en entrevistas?
- Reduce pasos?
- Hace la app mas simple?
- Aumenta la confianza?
- Es necesaria para el MVP?

Si la mayoria de las respuestas son "no", no implementarla.

## Prioridad comercial inmediata

Para una demo ante una cooperativa agricola, priorizar:

- Explicar Agronex como ecosistema modular.
- Mostrar NexuDrive como primer modulo concreto, usable y enfocado.
- Flujo de contratacion de camion claro y realista.
- Estados visibles que reduzcan llamadas y mensajes.
- Datos de ejemplo creibles para productores, transportistas, ubicaciones, cargas, horarios y pagos.
- Confianza: reputacion, estado del servicio, condiciones claras y trazabilidad minima.
- Coherencia de marca Agronex en textos visibles.

## Mensaje estrategico

Agronex tiene una vision grande, pero no intenta hacer todo junto.

La propuesta es construir un ecosistema agro modular donde cada modulo resuelva un problema real y pueda venderse por su propio valor. El primer paso es NexuDrive porque la contratacion y coordinacion de transporte es un problema urgente, validado y frecuente.
